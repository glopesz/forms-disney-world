# Formulário de Agendamento Disney World

Projeto acadêmico desenvolvido para a disciplina **Aplicações Para Internet**. A página apresenta um formulário de agendamento de atividades com uma interface temática inspirada em uma visita ao Walt Disney World.

## Funcionalidades

- Formulário dividido em seções para dados pessoais, visita, preferências e confirmação.
- Campos HTML para texto, e-mail, senha, data, horário, seleção de cor, intervalo e upload de arquivo.
- Layout responsivo com estilos personalizados.
- Interface em português brasileiro.

## Tecnologias

- HTML5
- CSS3

## Como visualizar

Abra [`disney.html`](./disney.html) em um navegador. O arquivo [`disney.css`](./disney.css), na mesma pasta, contém os estilos da página.

## Envio do formulário

O formulário está configurado para enviar os dados por `POST` para `agendaDisney.php` e permite anexar um arquivo. Esse script PHP não está incluído neste projeto; portanto, o envio só funcionará quando um backend compatível for criado e executado em um servidor com suporte a PHP.

# Disney World Activity Booking Form

Academic project developed for the **Internet Applications** course. This page presents an activity booking form with a themed interface inspired by a visit to Walt Disney World.

## Features

- Form divided into sections for personal details, visit information, preferences, and confirmation.
- HTML fields for text, email, password, date, time, color selection, range, and file upload.
- Responsive layout with custom styles.
- User interface in Brazilian Portuguese.

## Technologies

- HTML5
- CSS3

## How to view

Open [`disney.html`](./disney.html) in a web browser. The [`disney.css`](./disney.css) file in the same folder contains the page styles.

## Form submission

The form is configured to send data via `POST` to `agendaDisney.php` and supports a file attachment. That PHP script is not included in this project, so submission will only work after a compatible backend is created and run on a PHP-enabled server.
